Tiny Windowsill

Plant seeds and grow three little flowers.

  • JavaScript
  • Browser game
Play game — Tiny Windowsill → View code — Tiny Windowsill
Behind the game

A browser gardening game where you plant seeds, choose a watering can and grow three flowers. Each plant grows independently, and your garden is saved between visits.

JavaScript I practised

  • Arrays and objects: storing each plant’s watering count and planting status.
  • Event listeners: responding to tool selection, watering and resetting.
  • Conditions and DOM updates: changing growth stages, instructions and button states.
  • filter(): counting how many flowers have bloomed.
  • localStorage and JSON: saving and restoring the garden.
  • setTimeout(): controlling the watering animation.

Key functions

selectTool() renderGarden() saveGarden() loadGarden() showWatering()

Cat Café Rush

Serve the right orders before patience runs out.

  • JavaScript
  • Browser game
Play game — Cat Café Rush → View code — Cat Café Rush
Behind the game

A 45-second café game where you match menu items to customer orders. Correct orders earn points, mistakes reduce patience, and customers become less patient as your score increases.

JavaScript I practised

  • Arrays and objects: defining the café menu and tracking the current order.
  • Math.random() and Math.floor(): selecting customer orders.
  • dataset and event listeners: identifying and checking the item served.
  • State and conditions: managing scoring, difficulty and customer transitions.
  • Date.now() and setInterval(): measuring the round time and remaining patience.
  • Timeouts and CSS classes: displaying popups and animating departing customers.

Key functions

startGame() nextCustomer() serveItem() updateTimers() getCustomerDuration() loseCustomer() showPopup() endGame()
